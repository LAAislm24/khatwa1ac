Tâche 4 : Réduire des expressions de la forme ax + bx

1. اختزال تعبير حرفي من الشكل ax + bx

لاختزال تعبير حرفي يتكون من حدود تحتوي على نفس الحرف (المجهول)، نقوم بجمع أو طرح المعاملات (الأعداد) ونحتفظ بنفس الحرف.

القاعدة (Règle) : مهما كانت الأعداد a و b و x :
ax + bx = (a + b)x
ax - bx = (a - b)x
Exemples (أمثلة تطبيقية) :
• A = 5x + 3x = (5 + 3)x = 8x
• B = 7y - 2y = (7 - 2)y = 5y
• C = -4a + 9a = (-4 + 9)a = 5a
• D = x + 6x = 1x + 6x = 7x (ملاحظة: x تعني 1x)
Tâche 5 : Réduire et simplifier des expressions littérales

2. تبسيط واختزال تعبير حرفي مركب

لتبسيط تعبير حرفي طويل، نقوم بتجميع الحدود المتشابهة مع بعضها (الحروف التي لها نفس الأس معاً، والأعداد المعلومة معاً)، ثم نحسب كل مجموعة على حدة.

⚠️ تنبيه مهم جداً :
لا يمكن جمع 3x مع 5 (تبقى 3x + 5 ولا تساوي 8x).
كما لا يمكن جمع x² مع x (تبقى x² + x).
Exemples (أمثلة) :
• E = 4x + 7 + 2x - 3
  E = (4x + 2x) + (7 - 3)
  E = 6x + 4

• F = 3x² + 5x - x² + 2x + 8
  F = (3x² - x²) + (5x + 2x) + 8
  F = 2x² + 7x + 8
