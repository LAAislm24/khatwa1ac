Leçon 6 : Équations du premier degré à une seule inconnue

المعادلات من الدرجة الأولى بمجهول واحد (Tâche 1 إلى Tâche 9)

Tâche 1 : Vérifier si un nombre est solution d'une équation

1. التحقق من أن عدداً هو حل لمعادلة

للتحقق مما إذا كان العدد حلّاً للمعادلة، نعوض المجهول x بذلك العدد: إذا حصلنا على نفس القيمة في الطرفين، فهو حل للمعادلة.

Exemple : Est-ce que 3 est solution de 2x + 1 = 7 ?
Pour x = 3 : 2(3) + 1 = 6 + 1 = 7. Donc 3 est solution.
Tâche 2, 3 & 4 : Résoudre x + b = c et ax = c

2. حل المعادلات البسيطة ونقل الحدود

عند نقل حد من طرف إلى آخر في المعادلة نغير إشارته. وللتخلص من معامل مضروب في x نقسم الطرفين على ذلك المعامل.

x + b = c ➔ x = c - b   |   ax = c ➔ x = c / a (a ≠ 0)
Exemples :
• x + 5 = 12 ➔ x = 12 - 5 ➔ x = 7
• 4x = -20 ➔ x = -20 / 4 ➔ x = -5
Tâche 5, 6, 7 & 8 : Équations générales, fractions et parenthèses

3. حل المعادلات المركبة والكسور والأقواس

لحل معادلة مركبة: 1) ننشر الأقواس أو نوحد المقامات، 2) نجمع المجاهيل في طرف والمعاليم في الطرف الآخر مع تغيير الإشارة، 3) نبسط ونحسب قيمة x.

x / d = c / e ➔ e × x = c × d  (الجداء المتصالب)
Exemples :
• 5x - 3 = 2x + 9 ➔ 5x - 2x = 9 + 3 ➔ 3x = 12 ➔ x = 4
• 2(x + 3) = 14 ➔ 2x + 6 = 14 ➔ 2x = 8 ➔ x = 4
• x / 3 = 4 / 5 ➔ 5x = 12 ➔ x = 12/5 = 2,4
