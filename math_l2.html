📐 Tâche 1 : Additionner deux nombres entiers avec la droite numérique (p. 17)

📌 1. الشرح المبسط والأمثلة التطبيقية :
• نقطة البداية (Point de départ) : نحدد دائماً مكان العدد الأول على المستقيم العددي.
• إضافة عدد موجب (Ajouter un nombre positif +) : نتحرك نحو اليمين (vers la droite) بعدد خطوات يساوي ذلك العدد.
• إضافة عدد سالب (Ajouter un nombre négatif -) : نتحرك نحو اليسار (vers la gauche) بعدد خطوات يساوي ذلك العدد.

أمثلة تطبيقية (Exemples) :
1. (-2) + (+5) = +3 : نبدأ من -2، ثم نتحرك 5 خطوات نحو اليمين لنصل إلى +3.
2. (+3) + (-4) = -1 : نبدأ من +3، ثم نتحرك 4 خطوات نحو اليسار لنصل إلى -1.
3. (-1) + (-3) = -4 : نبدأ من -1، ثم نتحرك 3 خطوات نحو اليسار لنصل إلى -4.

📐 Tâche 2 : Additionner avec la valeur absolue

📌 1. الشرح المبسط والأمثلة التطبيقية :
القيمة المطلقة (La valeur absolue) لعدد هي مسافته عن الصفر (أي العدد بدون إشارة + أو -). لجمع عددين صحيحين نستعمل قاعدتين :

• الحالة 1 : لهما نفس الإشارة (Même signe) : نحتفظ بنفس الإشارة، ونجمع العددين (القيمتين المطلقتين).
• الحالة 2 : لهما إشارتان مختلفتان (Signes contraires) : نأخذ إشارة العدد الأكبر مسافة عن الصفر، ونطرح العدد الأصغر من الأكبر.

أمثلة تطبيقية (Exemples) :
1. (-4) + (-6) = -10 : نفس الإشارة (سالب)، نحتفظ بـ - ونجمع 4 + 6 = 10.
2. (+8) + (-3) = +5 : إشارتان مختلفتان، 8 أكبر من 3 إذن الإشارة +، ونطرح 8 - 3 = 5.
3. (-9) + (+2) = -7 : إشارتان مختلفتان، 9 أكبر من 2 إذن الإشارة -، ونطرح 9 - 2 = 7.
✍️ 2. تمارين للمراجعة (6 Questions d'entraînement بالاختيارات) :

سؤال 1 (تحديد القاعدة) : لجمع عددين لهما نفس الإشارة مثل (-5) + (-7)، ماذا نفعل؟


سؤال 2 (نفس الإشارة - سالب) : احسب : (-6) + (-8)


سؤال 3 (إشارتان مختلفتان) : احسب : (-12) + (+5)
• إشارة النتيجة هي :  |  • النتيجة النهائية :

سؤال 4 (إشارتان مختلفتان) : احسب : (+15) + (-9)


سؤال 5 (أعداد كبيرة) : احسب : (-25) + (+10)


سؤال 6 (مسألة تطبيقية) : غواصة على عمق -40m، صعدت بـ +15m. في أي عمق أصبحت؟

📐 Tâche 3 : Utiliser la commutativité et l'associativité de l'addition

📌 1. الشرح المبسط والأمثلة التطبيقية :
لتسهيل حساب مجموع عدة أعداد نسبية، نستخدم خاصيتين مهمتين :
• التبادلية (La commutativité) : يمكننا تغيير ترتيب الحدود في الجمع دون أن يتغير المجموع.
• التجميعية (L'associativité) : يمكننا تجميع الأعداد الموجبة معاً والأعداد السالبة معاً، أو تجميع الأعداد المتقابلة (التي مجموعها 0).

أمثلة تطبيقية (Exemples) :
1. A = (-5) + (+8) + (+5) + (-2)
نجمع المتقابلين أولاً : [(-5) + (+5)] + [(+8) + (-2)] = 0 + (+6) = +6.
2. B = (-4) + (+7) + (-6) + (+3)
نجمع السالبة معاً والموجبة معاً : [(-4) + (-6)] + [(+7) + (+3)] = (-10) + (+10) = 0.
✍️ 2. تمارين للمراجعة (6 Questions d'entraînement بالاختيارات) :

سؤال 1 (مفهوم الخاصية) : ماذا تعني خاصية التبادلية (Commutativité) في الجمع؟


سؤال 2 (تجميع الأعداد المتقابلة) : احسب بذكاء : (-9) + (+14) + (+9)


سؤال 3 (تجميع حسب الإشارة) : في العملية (-3) + (+5) + (-7) + (+2)، ما هو مجموع الأعداد السالبة فقط؟


سؤال 4 (إكمال الحساب) : احسب المجموع الكلي : (-3) + (+5) + (-7) + (+2)


سؤال 5 (حساب سريع) : احسب : (+12) + (-8) + (-12) + (-2)


سؤال 6 (تطبيق عددي) : احسب : (-15) + (+20) + (-5) + (+10)

📐 Tâche 4 : Effectuer la soustraction de nombres entiers

📌 1. الشرح المبسط والأمثلة التطبيقية :
القاعدة الذهبية للطرح : لطرح عدد صحيح، نضيف مقابله (On ajoute son opposé).
• نحتفظ بالعدد الأول كما هو.
• نحول عملية الطرح (-) إلى جمع (+).
• نعكس إشارة العدد الثاني (الموجب يصبح سالباً، والسالب يصبح موجباً).

أمثلة تطبيقية (Exemples) :
1. (+5) - (+8) = (+5) + (-8) = -3
2. (-4) - (-9) = (-4) + (+9) = +5
3. (-6) - (+3) = (-6) + (-3) = -9

سؤال 1 (تحويل الطرح إلى جمع) : كيف نكتب العملية (+7) - (-4) على شكل جمع؟


سؤال 2 (حساب مباشر) : احسب : (+7) - (-4)


سؤال 3 (طرح عدد موجب) : احسب : (-5) - (+6)

سؤال 5 (طرح من الصفر) : احسب : 0 - (-12)

📐 Tâche 5 : Additionner et soustraire dans des expressions numériques

📌 1. الشرح المبسط والأمثلة التطبيقية :
لحساب تعبير جبري يحتوي على الجمع والطرح والأقواس :
1. إذا كانت هناك أقواس داخلية : نحسب ما بداخل الأقواس أولاً.
2. إذا كانت سلسلة عمليات بدون أقواس : نحول كل عمليات الطرح إلى جمع المقابل، ثم نجمع الأعداد الموجبة معاً والسالبة معاً.
3. تبسيط الكتابة : +(+) = + ، +(-) = - ، -(+) = - ، -(-) = +.

مثال تطبيقي (Exemple) :
E = (-3) - (-5) + (-7) - (+2)
E = (-3) + (+5) + (-7) + (-2)
E = (+5) + [(-3) + (-7) + (-2)] = (+5) + (-12) = -7

سؤال 2 (حساب تعبير بسيط) : احسب : A = -4 + 6 - 2


سؤال 3 (الأولوية للأقواس) : في التعبير B = 10 - (3 - 8)، ما هي قيمة ما بداخل القوس (3 - 8) ؟


سؤال 4 (إكمال الحساب) : احسب النتيجة النهائية للتعبير : B = 10 - (3 - 8)

📐 Tâche 6 : Appliquer les règles aux nombres décimaux et aux fractions

📌 1. الشرح المبسط والأمثلة التطبيقية :
قواعد جمع وطرح الأعداد الصحيحة (الإشارات، القيمة المطلقة، وطرح المقابل) تبقى نفسها تماماً بالنسبة للأعداد العشرية (Décimaux) والكسور (Fractions) :
• الأعداد العشرية : ننتبه لوضع الفاصلة تحت الفاصلة عند الجمع أو الطرح.
• الكسور : يجب توحيد المقامات (Même dénominateur) أولاً، ثم نطبق قواعد الإشارات على البسطين.

أمثلة تطبيقية (Exemples) :
1. (-2,5) + (-1,5) = -4 (نفس الإشارة : نجمع ونحتفظ بـ -).
2. (+3,2) - (+5,7) = (+3,2) + (-5,7) = -2,5.
3. (-3/4) + (+1/4) = (-3 + 1) / 4 = -2/4 = -1/2.

سؤال 3 (طرح عددين عشريين) : احسب : (+1,5) - (-3,5)


سؤال 4 (كسور بنفس المقام) : احسب : (-5/7) + (+2/7)

📐 Tâche 7 : Résoudre un problème en utilisant l'addition et la soustraction

📌 1. الشرح المبسط ومنهجية حل المسائل :
لحل مسألة باستعمال الأعداد النسبية، نترجم الكلمات إلى إشارات (+ أو -) :
• إشارة موجبة (+) : ربح، صعود، ارتفاع، إيداع مبلغ، فوق سطح البحر، بعد الميلاد.
• إشارة سالبة (-) : خسارة، نزول، انخفاض، سحب مبلغ، تحت سطح البحر، قبل الميلاد.
• حساب الفرق أو المدة : دائماً نستعمل الطرح : النهاية - البداية.

مثال تطبيقي (Exemple) :
تاجر خسر 150 DH في الصباح (-150)، وربح 230 DH في المساء (+230).
الحصيلة هي : (-150) + (+230) = +80 DH (إذن ربح 80 DH).
